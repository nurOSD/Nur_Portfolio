# MD. NUR ISLAM — Quality Assurance Engineer

A bespoke, high-precision personal portfolio showcasing expertise as a **Quality Assurance Engineer** specializing in **Manual Testing** and **AI-Powered QA**.

---

## ✨ Highlights & Features

- **Quality Assurance Engineer Identity:** Officially crafted for Quality Assurance, QA Engineer, and Test Engineering roles.
- **Manual + AI Testing Synergy:** Blending deep human exploratory testing, user empathy, and boundary analysis with cutting-edge AI prompt engineering and synthetic test data generation.
- **Full STLC Coverage:** Manual testing, exploratory testing, boundary value analysis (BVA), regression suites, and bug life cycle in Jira.
- **Dual Standard Color Themes:** 1-Click instant toggle between **Standard Clean Dark (`#09090b`)** and **Standard Clean Light (`#f8fafc`)** with `localStorage` persistence.
- **Tactile Web Audio:** Micro-haptic click sounds synthesized live via the Web Audio API (with instant mute toggle).
- **Zero Build-Step & Blazing Fast:** Pure HTML5, modern Tailwind CSS, and vanilla JavaScript. 100/100 Lighthouse performance out of the box.

---

## 🛠️ Testing Toolkit & Core Competencies

- **Manual Testing:** Test Case Design, Test Scenarios, RTM, Regression, Exploratory, Smoke/Sanity, UAT, BVA, Equivalence Partitioning
- **AI in QA:** AI Test Case Generation, Prompt Engineering for QA, Synthetic Test Data, Visual AI Testing, Edge-Case Discovery
- **API & Defect Tracking:** Postman, REST API Testing, Jira Software, Bug Life Cycle, Git / GitHub, Agile / Scrum

## 🚀 Local Development Setup

To run the portfolio locally on your machine:

```powershell
# Using the built-in zero-dependency server:
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Then visit **`http://localhost:3000`** in any web browser.
